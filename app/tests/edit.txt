# The word editor in the simulator (from 0.5.0): SEL steps the knob pages (EDIT did until then); EDIT opens the editor
# on the slot sung, the keys type (A..Z bottom up, the top key a space), K1 moves, K2 changes, OCT- / OCT+ delete, PLAY
# tries, SAVE keeps (through a reboot), EDIT / HOME leave (unsaved: twice), PRESET picks another slot, FX switches the
# keys between A-Z and QWERTY in two rows.
#   python base/tools/build.py app --host; app/build/host/fmb-vocal_host app/tests/edit.txt app/build/host
